# law_file: previous spec versions

Put last year's specification PDFs here, e.g. `Verfahrensbeschreibung_DTA_EEL_Version_13.3.pdf`.

When a new version is dropped into the page, the pipeline matches it to the file here with the most
similar section headings and diffs the two section by section. If nothing here matches, or the folder
is empty, the new document is used on its own (its change log, or its most rule-heavy sections).

See [pipeline/README.md](../../pipeline/README.md).
